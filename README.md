# DotNetCore-AuthSystem

A production-ready Authentication & Authorization System built using ASP.NET Core Web API and Angular.

## Overview

This project demonstrates secure authentication and role-based authorization implementation using JWT Token, Refresh Token, and Role-Based Access Control (RBAC).

The system is designed following enterprise-level architecture and best practices for scalable web applications.

## Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Refresh Token
- Change Password
- Forgot Password (Coming Soon)

### Authorization
- Role-Based Access Control (RBAC)
- Admin Role
- Manager Role
- Employee Role
- Permission-Based Access

### Security
- Password Hashing
- JWT Token Validation
- Refresh Token Management
- Secure API Endpoints
- Middleware-based Exception Handling

### API Documentation
- Swagger Integration
